Capítulo 9: Conviértete en Estrella Retro

9.1 Estudio de Transmisión

Requisitos Mínimos:
→ CPU: 4 núcleos / 8 hilos
→ GPU: NVENC o AMF compatible
→ RAM: 8GB (16GB para 4K)
→ Ancho de Banda: 10Mbps upload

9.2 Configuración OBS Profesional

Plataforma Resolución Bitrate Preset
Twitch 936p (1664×936) 6000 Kbps NVENC (Calidad)
YouTube 1440p (2560×1440) 12000 Kbps CRF 18 (Slow)

9.3 Magia de RetroArch

  • Streaming nativo: 
    Settings → Streaming → Twitch/YouTube Keys
  • Captura directa: 
    FFmpeg params: -c:v libx264 -preset ultrafast
  • Overlays retro: 
    Usar .png con canal alpha → 30% opacidad

9.4 Configuraciones de Élite

🎮 Steam Deck:

OBS → Sources → Game Capture → RetroArch (Vulkan)
→ Bitrate: 4000 Kbps (H.265)
→ Resolución: 1280×800 (nativa)

📱 Android:

Larix Broadcaster + Screen Capture
→ Codec: HEVC @ 5Mbps
→ Audio: AAC 192kbps

9.5 Postproducción Maestra

Software Uso Ventaja Clave
DaVinci Resolve Corrección color CRT Nodos 16-bit
HandBrake Compresión eficiente Preset Retro (AV1)
Audacity Mezcla audio chiptune Filtro Low-pass 15kHz

9.6 Reglas del Juego

  • ⚠️ Evitar música con copyright (usar MOD)
  • 📜 Añadir disclaimer "Juego propiedad de [Compañía]"
  • 🔒 No exponer claves de API en streams
