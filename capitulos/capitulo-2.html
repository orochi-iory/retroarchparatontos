Capítulo 2: Descarga e Instalación

2.1 Descarga Segura

🔒 Solo descarga desde fuentes oficiales:

https://www.retroarch.com → Downloads → Tu plataforma

❌ Evitar: Sitios de terceros y versiones modificadas

2.2 Instalación Multiplataforma

Plataforma Pasos Notas
🖥️ Windows 
1. Ejecutar .exe
2. Instalar en C:\RetroArch
3. Marcar "Core Updater"
 Evitar espacios en rutas
📱 Android 
1. Habilitar fuentes desconocidas
2. Instalar APK
3. Otorgar permisos
 Usar mando Bluetooth
🎮 Steam Deck 
1. Modo Desktop
2. Instalar desde Discover
3. Añadir a Steam
 Usar Proton Experimental

2.3 Actualización

  • Windows/Steam Deck: Sobreescribir instalación
  • Android: Reinstalar APK
  • Linux: Actualizar desde repositorio
Configuración → Guardar Configuración Actual (hacer backup)

2.4 Problemas Comunes

Error Solución Urgencia
❌ Faltan DLLs Instalar VC++ Redist ⚠️ Crítico
🛡️ Bloqueo Antivirus Añadir excepción ⚠️ Importante
🐢 Rendimiento bajo Desactivar shaders ⚡ Optimización

2.5 Configuración Inicial

1. Settings → Drivers → Menu → Ozone
2. Settings → Directory:
   - ROMs: /retroarch/roms
   - Saves: /retroarch/saves
3. Guardar configuración

2.6 Preguntas Frecuentes

❓ ¿Es seguro RetroArch?
✅ Sí, si se descarga de la web oficial

❓ ¿Funciona en macOS?
✅ Sí, versión Universal en la web
