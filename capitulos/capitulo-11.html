# Instalación RetroPie
sudo apt install git lsb-release
git clone --depth=1 https://github.com/RetroPie/RetroPie-Setup.git
cd RetroPie-Setup
sudo ./retropie_setup.sh

Trucos de Rendimiento

Overclock Seguro (Pi 4):

# /boot/config.txt
over_voltage=2
arm_freq=1500
gpu_freq=600

🌡️ Mantener temperatura < 70°C
