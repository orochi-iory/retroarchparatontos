Capítulo 5: El Corazón de RetroArch

5.1 Anatomía de un Núcleo

💾 Definición: Ejecutables que contienen todo el hardware virtual necesario para emular un sistema

┌──────────────────┐
│  Núcleo          │
│  ├ CPU Emulada   │
│  ├ Chip de Audio │
│  └ GPU Virtual   │
└──────────────────┘

5.2 Descarga e Instalación

1. Menú Principal → Cargar Núcleo → Descargar Núcleo
2. Buscar por sistema o nombre:
   - Nintendo (SNES) → bsnes
   - Sony (PS1) → Beetle PSX HW
3. Instalación automática en:
   /retroarch/cores

💡 Usa Online Updater → Actualizar Núcleos para mantenerlos al día

5.3 Selección de Élite

Sistema Núcleo Foco Requisitos
SNES bsnes Precisión 100% CPU 4 núcleos
PS1 Beetle PSX HW Gráficos HD GPU Vulkan
N64 Mupen64Plus-Next Compatibilidad OpenGL 3.3+

5.4 Ajustes Específicos por Núcleo

  • 🎮 Beetle PSX HW → Aumentar resolución interna a 8x
  • 🖥️ bsnes → Activar "HD Mode 7" para efectos 3D
  • 💾 mGBA → Overclock al 200% para juegos lentos
Quick Menu → Opciones
   → Buscar parámetros específicos del núcleo
   → Guardar como Override de Núcleo

5.5 La Sala de Emergencias

Error Causa Solución
❌ No carga ROM Formato incompatible Convertir a .chd/.cue
💥 Crash al iniciar BIOS faltante Colocar en /retroarch/system
🐌 Rendimiento pobre Núcleo muy demandante Usar versión ligera (Ej: Snes9x)

5.6 Preguntas de la Comunidad

❓ ¿Son legales los núcleos?
✅ Sí, son código abierto. Solo necesitas ROMs/BIOS legales.

❓ ¿Puedo usar múltiples núcleos para un sistema?
✅ Sí, prueba diferentes núcleos para comparar rendimiento.
