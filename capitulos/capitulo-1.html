Capítulo 1: ¿Qué es la emulación?

1.1 La máquina del tiempo digital

⚠️ Definición clave: Software que imita hardware antiguo

┌──────────────┐   ┌───────────┐   ┌───────┐
│  Dispositivo │ → │ Emulador  │ → │  ROM  │
│  Moderno     │   │ (RetroArch│   │(Juego)│
└──────────────┘   └───────────┘   └───────┘

1.2 Componentes esenciales

Elemento Función Ejemplo
🛠️ Emulador Traduce instrucciones del hardware antiguo RetroArch, Dolphin
💾 ROM Copia digital del juego original SuperMarioWorld.sfc
🔐 BIOS Firmware de la consola original SCPH1001.bin (PS1)

1.3 Mitos comunes

  • 🚫 "La emulación es ilegal" → ✅ Los emuladores son legales
  • 🚫 "Solo para expertos" → ✅ RetroArch simplifica el proceso
  • 🚫 "Pierde calidad original" → ✅ Shaders mejoran la experiencia

1.4 Ventajas de RetroArch

✔️ Interfaz unificada
✔️ +50 sistemas compatibles
✔️ Cross-platform (Windows/Mac/Linux/Android)
✔️ Mejoras gráficas (shaders CRT, HD)
✔️ Sistema de guardado avanzado

1.5 Primeros pasos prácticos

⚙️ Ejemplo SNES:

1. Descargar RetroArch
2. Instalar core "bsnes"
3. Buscar ROM .sfc
4. ¡Jugar con autenticidad CRT!

🎮 Requisitos mínimos: CPU dual-core, 2GB RAM

1.6 Preguntas Frecuentes

Pregunta Respuesta
¿Es legal usar BIOS? Solo si lo extraes de tu consola
¿Necesito PC potente? Depende del sistema a emular
¿Dónde conseguir ROMs? Solo de juegos que poseas físicamente
