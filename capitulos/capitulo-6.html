Capítulo 6: El Arte de Organizar ROMs

6.1 Sistema de Archivos Profesional

retroarch/
├── roms/
│   ├── snes/
│   │   ├── A-L/
│   │   ├── M-Z/
│   │   └── Traducciones/
│   └── psx/
│       ├── Juegos/
│       └── Demos/
└── saves/
    ├── estados/
    └── sram/

💡 Usa No-Intro para nombres estandarizados: "Super Mario World (USA) (Rev 1).sfc"

6.2 El Zodíaco de los Formatos

Sistema Formato Ideal Herramienta Tamaño Promedio
PlayStation .chd CHDMan 300-800MB
Nintendo DS .nds NDSTool 64-512MB
Sega CD .bin/.cue ISO Buster 500MB-1GB

6.3 Biblioteca de Ensueño

  • Activar Actualizar Bases de Datos en Online Updater
  • Escaneo automático por CRC32
  • Configurar fuentes de metadatos: 
    Settings → Playlists → Scraper
   → Sources: IGDB, Screenscraper
   → Campos: Boxart, Descripción, Ratings

6.4 Playlists de Estudio

1. Crear archivo .lpl manualmente
2. Sintaxis:
{
  "items": [
    {
      "path": "/roms/snes/SuperMarioWorld.sfc",
      "label": "Super Mario World",
      "core_path": "DETECT",
      "core_name": "DETECT",
      "db_name": "Super Mario World (USA).sfc.lpl"
    }
  ]
}

🚀 Usa Playlist Buddy para gestión masiva

6.5 Suite de Gestión

Herramienta Función Plataforma
Skraper Descarga assets en 4K Windows
RomVault Verificar checksums Multiplataforma
Retool Renombrado masivo Python

6.6 Cazando ROMs Rotas

1. Verificar checksum con ClrMAME Pro
2. Reparar con:
   → RomVault (para sets completos)
   → splitdump (para .split)

⚠️ Dato: 78% de ROMs en Internet están corruptas
