Capítulo 3: Dominando la Configuración

3.1 Personalización de la Interfaz

Settings → User Interface → Menu
   → Menu Driver: ozone
   → Menu Scale Factor: 1.5x
   → Menu Color Theme: Classic Green

💡 Usa XMB para una experiencia tipo PlayStation 3

3.2 Configuración de Drivers

Driver Recomendado Descripción
Video Vulkan Máximo rendimiento para GPUs modernas
Audio ALSA (Linux)
WASAPI (Windows)		 Baja latencia
Input udev (Linux)
XInput (Windows)		 Soporte para mandos modernos

3.3 Atajos de Teclado/Mando

  • F1 → Menú rápido
  • F2 → Guardar estado
  • F4 → Cargar estado
  • L3 + R3 → Resetear juego
Settings → Input → Hotkeys
   → Configure cada atajo según preferencias

3.4 Ajustes para Hardware Limitado

Settings → Video
   → Threaded Video: ON
   → VSync: OFF
   → Hard GPU Sync: ON
   → Frame Delay: 2

⚠️ Nota: Aumentar Frame Delay puede causar inestabilidad

3.5 Preconfiguraciones Gráficas

Tipo Shader Recomendado Uso
CRT crt-royale Autenticidad arcade
HD xBRZ-Freescale Juegos 2D en 4K
Portátil lcd-grid Simular Game Boy

3.6 Gestión de Perfiles

  • 💾 Guardar configuración global: Main Menu → Configuration File → Save
  • 🎮 Perfiles por núcleo: Quick Menu → Overrides → Save Core Overrides
  • 🕹️ Perfiles por juego: Quick Menu → Overrides → Save Game Overrides
