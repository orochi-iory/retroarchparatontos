7.3 Taller del Alquimista

  • 📁 Instalar shaders: 
    Online Updater → Actualizar Shaders
  • 🎨 Aplicar preset: 
    Quick Menu → Shaders → Cargar Preestablecido → crt/crt-royale.slangp
  • ⚙️ Ajustes avanzados: 
    #define CURVATURE 0.15 // 0.0-1.0
#define SCANLINE_STRENGTH 0.75

7.4 Recetas de la Perfección

🕹️ Mega Drive/Genesis:

shaders = "crt-royale.slangp"
parameters = {
    "mask_type": "2",
    "gamma": "1.1",
    "scanlines": "0.8"
}

📱 Game Boy Pocket:

shaders = "handheld/lcd-grid-gb.slangp"
parameters = {
    "pixel_grid": "0.6",
    "display_color": "#8BAC0F"
}

7.6 Convirtiéndote en Mago

// Ejemplo: Scanlines básicos
void main() {
    vec3 color = texture2D(u_texture, v_tex_coord).rgb;
    float scanline = sin(v_tex_coord.y * 1000.0) * 0.1;
    gl_FragColor = vec4(color - scanline, 1.0);
}
